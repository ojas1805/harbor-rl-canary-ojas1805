# AI Agent Transcripts

This directory contains the successful Harbor `terminus-2` agent execution trajectories for the payment reconciliation task.

| Experiment | Trial | File |
|---|---|---|
| Baseline | 1 | baseline_trial_1.json |
| Baseline | 2 | baseline_trial_2.json |
| Ablation | 1 | ablation_trial_1.json |
| Ablation | 2 | ablation_trial_2.json |

Each JSON file records an agent's interaction with the task environment. The original trajectory files are also preserved in `jobs_summary/`.

The rate-limit error trajectories are retained in `jobs_summary/` and are not counted as successful trials.
